# 首页地图导航生命周期修复设计

## 目标

修复首页地图的两个关联问题：点击省份离场时 Edge 将 SVG 焦点轮廓绘制成黑色碎块和白色弧框；从省份页通过浏览器后退返回首页时，BFCache 恢复了已淡出为透明的地图容器。

## 约束

- 只调整首页地图的交互与样式，不修改省份数据和其他页面业务。
- 保留现有 0.4 秒淡出跳转效果。
- 保留键盘访问能力，以自定义 SVG 描边替代浏览器原生焦点轮廓。
- BFCache 恢复时复用现有地图 DOM 和事件监听器，不重复执行 `init()`。

## 方案

1. 在 `css/map.css` 中明确关闭省份 SVG path 的原生 `outline`，并用 `:focus-visible` 的描边和阴影显示键盘焦点。
2. 在 `js/map.js` 中集中管理地图容器、离场状态和跳转锁：点击时清除当前 path 焦点、隐藏 tooltip、给容器添加离场类，再执行原淡出动画。
3. 监听 `pagehide`，在文档进入历史缓存前清除离场动画的内联透明度和离场类。
4. 监听 `pageshow`；当 `event.persisted` 为真时，再次执行幂等恢复，覆盖不同浏览器的 BFCache 时序差异。

## 验证

- 点击省份 120ms 后，省份 path 不再具有浏览器原生 `outline: auto`，画面中不出现黑块或白色弧框。
- 跳转到省份页后执行浏览器后退，首页 `#map-container` 的计算透明度为 `1`，34 个省份 path 保持可见且可点击。
- 键盘 Tab 聚焦省份时仍有自定义可见焦点。
